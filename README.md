# AFOQT Pilot Trainer

Practice and timed simulation for every AFOQT subtest. Works offline once opened.

## Install on iPhone
1. Open the site in **Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Launch it from the home-screen icon. It opens full screen.

## Install on Android
Open the site in Chrome → menu (⋮) → **Install app**.

## Move progress from the old version
In the old version: Settings → **Export** → Copy code. In the app: Settings → **Import** → paste → Import → Replace my progress.
